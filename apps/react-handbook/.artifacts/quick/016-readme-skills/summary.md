# Summary: Document how to install the agent skills the rules require

## What Changed

Added an "Agent skills" subsection under "How this repo is built" in the README. It lists the four skills the rules require, the rule file behind each one, and the install command for each. The commands come from each skill's upstream README: the Skills CLI for `spec-driven` and `vercel-react-best-practices`, the `uipro` CLI for `ui-ux-pro-max`, and the Claude Code plugin marketplace for `humanizer`.
